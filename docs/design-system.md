# Design System — Tech Boho

## Conceito

A identidade do `jm.dev.br` combina minimalismo, calma visual e tecnologia.

## Paleta

- Canvas — `#F2EEE6`
- Ink — `#1B1D1A`
- Sand — `#D8CFC2`
- Clay — `#A66A4C`
- Moss — `#65735B`
- Titanium — `#8E9491`
- Digital — `#6E9FA3`

## Tipografia

- Headlines: Manrope
- Interface: Inter
- Código e labels: IBM Plex Mono

## Princípios

- Clareza antes de decoração
- Espaço em branco
- Poucas cores por tela
- Movimento curto e funcional
- Mobile first
- Acessibilidade WCAG AA
- Conteúdo e projetos em primeiro plano
