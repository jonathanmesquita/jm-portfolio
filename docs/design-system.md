# Design System — Tech Boho

## Conceito

A identidade do `jm.dev.br` combina minimalismo, calma visual e tecnologia.

## Paleta

- Canvas — `#F2EEE6`
- Ink — `#1B1D1A`
- Sand — `#D8CFC2`
- Clay — `#A66A4C`
- Moss — `#5F6D55`
- Titanium — `#8E9491`
- Digital — `#6E9FA3`

### Faixa escura do catálogo ("sala de projeção")

A seção Selected Work é uma faixa escura de ponta a ponta, com os mesmos tons:

- Superfície — Ink `#1B1D1A`; cartão e janela — `#262824` (`--color-ink-raised`)
- Texto — Canvas; texto secundário — `#C9C2B6` (`--color-on-ink-muted`)
- Selo "Live" — fundo `--color-clay-on-ink` com texto Ink; "Building" — fundo Sand
- Divisória — `--border-on-ink` (canvas a 16%)

Terracota substitui o vermelho de streaming: a referência é o formato (destaque, fileiras,
prévia no hover), não a marca de ninguém.

## Tipografia

Servidas pelo próprio site via Fontsource (sem chamada a Google Fonts):

- Headlines: Manrope
- Interface: Inter
- Código e labels: IBM Plex Mono

## Princípios

- Clareza antes de decoração
- Espaço em branco
- Poucas cores por tela
- Movimento curto e funcional
- Mobile first
- Acessibilidade WCAG AA
- Conteúdo e projetos em primeiro plano
